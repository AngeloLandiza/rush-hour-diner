# Rush Hour Diner

1–4 friends run a tiny meme-food stand that grows into a chaotic diner. It's a Roblox co-op restaurant tycoon, built entirely in code with Rojo.

## Setup

```sh
rokit install          # pinned toolchain
wally install          # packages
tools/check.sh         # lint + types + tests + build
rojo serve             # then Connect from the Rojo plugin in Studio
```

See `docs/GDD.md` for the design and `docs/ARCHITECTURE.md` for the code layout.
